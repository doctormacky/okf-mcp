## Index / 索引

* [English](#english)

## English

This folder names **attesters**: people, teams, or systems allowed to mark overlay Concepts reviewed or to sign attested computations.

Do not invent an attester. If none is known, leave this template and do not create a Concept file.

```yaml
---
type: Attester
title: Example attester
description: Replace with the real reviewer or signing system.
status: draft
---

# Example attester

* Role or system that may set overlay status to reviewed.
```

## 中文

本目录登记**证明方**：有权把覆盖层标为已审核、或为计算签名的人、团队或系统。

不要编造证明方。如果还不知道是谁，把模板留在这里，不要新建 Concept 文件。
